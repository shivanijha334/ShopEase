# 🛍️ ShopEase – E-Commerce Web Application

ShopEase is a full-stack **e-commerce web application** designed to provide users with a smooth and user-friendly online shopping experience. The application includes product browsing, user authentication, shopping cart management, checkout functionality, and backend REST APIs connected with a MongoDB database.

## ✨ Features

* 🔐 User Registration & Login
* 🛍️ Browse Products
* 📂 Product Categories
* 🔎 Product Details
* 🛒 Add to Cart
* ➕➖ Cart Management
* 💳 Checkout
* 📦 Order Management
* 🔗 REST API Integration
* 🗄️ MongoDB Database Integration
* 📱 User-Friendly Interface

## 🛠️ Technologies Used

**Backend**

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/shivanijha334/ShopEase.git
```

### 2. Navigate to the Server Folder

```bash
cd ShopEase/server
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Backend Server

```bash
node server.js
```

The backend server runs on:

```text
http://localhost:5000
```

### 5. Run the Frontend

Open the `client` folder using **Live Server** or another local development server.

## 🔌 API Endpoints

### User APIs

```text
POST /api/users/register
POST /api/users/login
```

### Product APIs
